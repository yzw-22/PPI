# SHS27k BFS 实验总结（readout / 超参数调优）

> 记录 main 分支 readout 三种模式与超参数（gamma、hidden、epochs、seed）的
> 全部对比实验。均为 CPU 本地运行，与 CUDA 服务器结果同分布但数值不可直接
> 混用；正式结论以多 seed 均值±std 为准。

## 结论（TL;DR）

1. **当前最优配置**：`v1 readout + hidden 128 + gamma 0.9 + 20 epochs`
   （seed 42）：test MacAUC 0.7275 / MicAUC 0.7315 / **MacF1 0.5090** /
   MicF1 0.5399，训练 2605 s。
2. **readout 对比**：纯 `attn`（m=u⊙v）明显落后（丢幅值/距离信息，MacF1
   均值 0.376）；`attn2`（m=concat(|u−v|, u+v, u⊙v)）大幅回升（0.440）但仍
   略低于 `v1`（0.464，3 seed 均值，差距在方差内）。v1 仍是默认。
3. **gamma 0.9 > 1.0**：对 v1 正面（MacF1 0.5025 vs 0.4765，s42/20ep），
   docs 示例命令即 0.9。
4. **hidden 128 > 256**：小数据（train 4562）下降容量减少过拟合且提速 ~35%
   （attn2 MacF1 +0.068，v1 +0.007，s42/20ep/g0.9）。
5. **方差纪律**：指标波动大（MacF1 0.36~0.51），任何结论需同 seed 配对 +
   多 seed 验证。

## 关键实验结论

- **attn vs attn2**：补回 `|u−v|`、`u+v` 后 MacF1 +0.064（2 seed 一致），
  确认"元素积丢信息"是纯 ⊙ 版落后的主因。
- **attn2 vs v1**：3 seed（s42/s111/s123，各 10-20ep）均值 MacF1 0.453 vs
  0.464，MacAUC 0.727 vs 0.732——无显著差异，v1 略优但差距在方差内；
  s123·20ep 单次 attn2 曾反超（0.4785 vs 0.4494），s42 两次均落后。
- **gamma 0.9**：v1 的 F1 明显受益（s42：MacF1 0.5025 vs g1.0 的 0.4765），
  attn2 无明显变化。
- **hidden 128**：两模式 F1 均提升（attn2 +0.068、v1 +0.007，s42/20ep/g0.9），
  epoch 时间 130 s vs 200 s（−35%），支持小数据域过拟合假设。
- **实现细节**：attn/attn2 的 `key_proj` 无 bias（softmax 平移不变性使共享
  key bias 梯度恒为 0）；readout 切换由 `--readout {v1,attn,attn2}` 控制，
  默认 v1 与历史 checkpoint 兼容。

## 建议基线命令

```bash
python -m src.train_shs27k \
  --dataset SHS27k --split bfs --device cuda \
  --epochs 20 --hidden-dim 128 --reinforce-gamma 0.9 \
  --seed 42 --output /tmp/ppi_best.json
```

## 待办 / 风险

- 最优配置（v1/h128/g0.9/20ep）仅 seed 42 单点，需扩 seed（111/123）确认。
- F1 固定阈值 0.5；pos_weight、阈值校准、结构特征（Adamic-Adar 等）尚未实验。
- 红线：推理特征只能来自 ESM embedding 与无标签拓扑，禁止边标签/测试标签。
