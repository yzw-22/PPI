# SHS27k BFS 实验总结（readout 历史结论 / 超参数调优 / sampler 打分架构）

> 记录 main 分支超参数（gamma、hidden、epochs、seed、max_steps、k_hops）的
> 全部对比实验，以及 readout 三种模式的**历史**结论（attn 机制代码已在提交
> `8a1bc79` 回退，当前代码只有 v1 路径，无 `--readout` 参数；attn 系列结论
> 保留作设计参考）。均为 CPU 本地运行，与 CUDA 服务器结果同分布但数值不可
> 直接混用；正式结论以多 seed 均值±std 为准。

## 结论（TL;DR）

1. **当前最优配置**：`v1 readout + hidden 128 + gamma 0.9 + 20 epochs +
   max_steps 5`（seed 42）：test MacAUC 0.7553 / MicAUC 0.7734 /
   **MacF1 0.5239** / MicF1 0.5758，训练 1406 s（~47% 快于 ms10）。
   （当前代码已为 res-score 打分，同配置 3-seed 配对见第 8 条。）
2. **readout 对比（历史，代码已回退）**：纯 `attn`（m=u⊙v）明显落后（丢幅值/
   距离信息，MacF1 均值 0.376）；`attn2`（m=concat(|u−v|, u+v, u⊙v)）大幅回升
   （0.440）但仍略低于 `v1`（0.464，3 seed 均值，差距在方差内）。**瓶颈修复
   实验（attn3/attn4，s42/ms5/h128/20ep/g0.9）证实 attn2 的 3d→d 压缩是主因**：
   attn3 去掉压缩后 MacF1 0.313→0.487、MacAUC 0.736→0.751（MacAUC 已与 v1
   打平）；但 MacF1 仍低于 v1（0.487 vs 0.524）——剩余差距在校准；attn4
   （v1 特征 + 上下文）0.485 < v1，说明注意力上下文本身净贡献为负。v1 仍是默认。
3. **gamma 0.9 > 1.0**：对 v1 正面（MacF1 0.5025 vs 0.4765，s42；注意 g1.0
   对照来自 10ep 记录，epoch 数与 gamma 混杂，20ep/g1.0 未跑，见待办），
   docs 示例命令即 0.9。
4. **hidden 128 > 256**：小数据（train 4562）下降容量减少过拟合且提速 ~35%
   （attn2 MacF1 +0.068，v1 +0.007，s42/20ep/g0.9）。
5. **k_hops 2 > 1**（s42/ms10/h256/g0.9，40ep vs 20ep）：val MacAUC 0.7587 vs
   0.7390，前 20 epoch 逐 epoch 对比 17/20 领先；test 四项全升（MacAUC
   0.7483 vs 0.7253、MicAUC 0.7609 vs 0.7493、MacF1 0.5246 vs 0.5025、MicF1
   0.5458 vs 0.5295）；mean_reward 0.01→0.019（候选池扩大后采样器学到更多）。
   但 test 仍低于 ms5/h128 最优（MacAUC 0.7483 vs 0.7553、MicF1 0.5458 vs
   0.5758，MacF1 持平 0.5246 vs 0.5239），且 40ep 后半段无额外收益（best
   epoch 34，35–40 回落）→ 单 seed，待扩 seed 验证。
6. **value baseline 删除（3 seed 配对，s42/s111/s123，20ep/g0.9/h256/ms10/k1）**：
   AUC/F1 差异全部在配对 ±1σ 内（valAUC +0.002±0.008、test MacAUC −0.003±0.008、
   MacF1 −0.017±0.055、MicF1 −0.019±0.073，F1 方向随 seed 翻转：s42/s111 降、
   s123 升）——**无显著指标收益**；唯一稳定收益是省时 ~13%（−648±132 s）与
   少一套参数。s111 无 baseline 版 bestEp=3 早峰后漂移，稳定性略降。结论：
   删除可接受（指标无显著损失）但非净提升。
7. **方差纪律**：指标波动大（MacF1 0.36~0.52），任何结论需同 seed 配对 +
   多 seed 验证。
8. **sampler 打分架构 v1-res（3 seed 配对，s42/s111/s123，ms5/h128/g0.9/20ep）**：
   `concat(state, cand) → Linear(2d→d)` 加回投影 state（残差）→
   `Linear(d→d//2) → LayerNorm → Tanh → Linear(d//2→1)` 打分头，取代原
   LeakyReLU pairwise MLP。配对 diff 全部为正：valAUC +0.008±0.008、MacAUC
   +0.004±0.005、MicAUC +0.005±0.005、**MacF1 +0.050±0.052（3/3 正）**、
   MicF1 +0.032±0.041（2/3 正，s42 微负 −0.013）；方差显著更小（MacF1 std
   0.024 vs 0.075，最差 seed s111 0.358→0.481）。结论：res-score 不劣于 v1
   且稳定性明显更好，保留为默认架构；与 h256/ms10、k2 组合未测。

## 关键实验结论

- **attn vs attn2**：补回 `|u−v|`、`u+v` 后 MacF1 +0.064（2 seed 一致），
  确认"元素积丢信息"是纯 ⊙ 版落后的主因。
- **attn2 vs v1**：3 seed（s42/s111/s123，各 10-20ep）均值 MacF1 0.453 vs
  0.464，MacAUC 0.727 vs 0.732——无显著差异，v1 略优但差距在方差内；
  s123·20ep 单次 attn2 曾反超（0.4785 vs 0.4494），s42 两次均落后。
- **gamma 0.9**：v1 的 F1 明显受益（s42：MacF1 0.5025 vs g1.0 的 0.4765；
  但 g1.0 对照来自 10ep 记录（总表 `v1 42 10 1.0` 行），epoch 数与 gamma
  混杂），
  attn2 无明显变化（同样混杂，0.4179 vs 0.4109）。
- **hidden 128**：两模式 F1 均提升（attn2 +0.068、v1 +0.007，s42/20ep/g0.9），
  epoch 时间 130 s vs 200 s（−35%），支持小数据域过拟合假设。
- **max_steps 5 vs 10**（s42/20ep/g0.9/h128）：v1 全面受益——MacAUC
  0.7275→0.7553、MacF1 0.5090→0.5239，epoch 时间 130 s→70 s（−47%，
  20ep 全程 1406 s）；attn2 的 MacAUC 微升（0.7177→0.7363）但 MacF1 崩
  塌（0.4784→0.3129），最佳 checkpoint 落在 epoch 2——短轨迹下 attn2
  验证 AUC 早峰后漂移，F1 停在过拟合早期，需多 seed 确认是否系统性不稳。
- **k_hops 2 vs 1**（s42/ms10/h256/g0.9，40ep vs 20ep）：val MacAUC 0.7587
  vs 0.7390，前 20 epoch 逐 epoch 17/20 领先（多数 +0.02~+0.07）；test 四
  项全升（见 TL;DR 第 5 条）。mean_reward 0.010→0.019：候选池扩大缓解了
  k1 下 frontier 快速耗尽导致的"被迫扩张"，采样器学到更充分的子图。但
  best epoch 34，40ep 后半段回落，且 test 仍低于 ms5/h128 最优
  （MacAUC 0.7483 vs 0.7553、MicF1 0.5458 vs 0.5758）——k2 方向正面，
  单 seed，待扩；k2 与 ms5/h128 的组合未测。
- **value baseline 删除**（s42 单点 → 3 seed 配对扩展，20ep/g0.9/h256/ms10/k1）：
  s42 上曾见 val MacAUC 0.7509 vs 0.7390 且 F1 降 ~0.025 的"排序-校准分离"；
  扩到 s111/s123 配对后该签名不成立——逐 seed 方向翻转（s42 MacF1 −0.024、
  s111 −0.081、s123 +0.053），3 seed 配对 diff 全部在 ±1σ 内（见 TL;DR
  第 6 条）。**value baseline 对最终指标无显著影响**；稳定收益仅省时 ~13%
  （均值 4258 s vs 4906 s，配对 std 132 s）与少一套参数。s111 no-val 的
  bestEp=3 早峰提示无 baseline 时策略梯度方差更大、验证曲线更抖。
- **sampler 打分 v1-res**（3 seed 配对，s42/s111/s123，ms5/h128/g0.9/20ep）：
  残差式 pair 投影 + LN/Tanh 打分头。配对 diff：MacAUC +0.004±0.005、
  MicAUC +0.005±0.005、MacF1 +0.050±0.052（3/3 正）、MicF1 +0.032±0.041
  （s42 −0.013、s111 +0.087、s123 +0.023）。关键收益在稳定性：v1 的 s111
  崩溃点（MacF1 0.358，bestEp=2 早峰）被 res 修复为 0.481（bestEp=14）；
  res 3-seed MacF1 std 0.024 vs v1 0.075。AUC 增益较小但 3/3 正。epoch 时间
  相当（约 60-80 s）。
- **实现细节**：attn/attn2 的 `key_proj` 无 bias（softmax 平移不变性使共享
  key bias 梯度恒为 0）；readout 切换曾由 `--readout {v1,attn,attn2}` 控制，
  attn 机制代码已在 `8a1bc79` 回退，当前模型只有 v1 路径（predictor 与
  23c984c 逐字节一致；sampler 另在 `8b22f09` 删除了 value_head），历史
  attn checkpoint 不再兼容当前代码。

## 设计分析：attn2 为何落后于理论预期（附文献）

1. **信息瓶颈（主因）**：attn2 的 pair 特征 m（3d）先经 `W_Q: 3d→d` 压成
   query，分类 MLP 只见 `[c; W_Q m]`；v1 将 `[u+v; |u−v|; 图均值]` 全量直通。
   |u−v| 逐维差异是 7 类判别主信号，线性压缩最易丢这类细粒度信号。算子对比
   文献无普适最优算子（concat 常居前），分类器应直接看到全部算子
   （[IJCAT 2023](https://dl.acm.org/doi/10.1504/ijcat.2023.134091)、
   [Sci Rep 2021](https://www.nature.com/articles/s41598-021-87987-1)）。
2. **超小上下文注意力退化**：softmax 只作用于非目标节点，k_hops=1 + RL 采样
   的子图典型 2–6 节点，context key 数 k=0~4：k=0 → c=0（注意力死亡，只剩
   压缩 pair 路径）；k=1 → 恒等复制；k=2~4 → 高方差近 one-hot。图注意力在
   特征可信、结构噪声高时反而有害（[ICML 2025 CSBM 理论](https://proceedings.mlr.press/v267/ma25w.html)、
   [Attention Might Offer Little Benefit](https://www.preprints.org/manuscript/202604.1443)、
   [GATv2](https://ar5iv.labs.arxiv.org/html/2105.14491)）。
3. **softmax 熵坍缩**：q/k 无范数约束，训练中 logits 方差增长 → 注意力熵
   坍缩（[EMNLP 2025](https://aclanthology.org/2025.emnlp-main.421/)），在
   1~4 个 key 下退化为随机选中一个邻居；attn2/ms5 的 "best epoch=2 后持续
   漂移"即其签名。
4. **RL 反馈回路**：可学习注意力使 loss 对子图构成不光滑 → 增量奖励
   `r_t=L_{t-1}−L_t` 噪声升高 → sampler 策略更差 → 子图更糟（负反馈闭环）；
   v1 的均值池化平滑，回路良性。
5. **排序-校准分离**：attn2/ms5 的 MacAUC 升（0.7177→0.7363）而 MacF1 崩
   （0.4784→0.3129）＝ ranking 保持但 logits 尺度/校准被破坏，固定 0.5
   阈值失配。

**瓶颈修复验证（attn3/attn4，s42/ms5/h128/20ep/g0.9）**：attn3（`[c; m]`
直通）MacF1 0.3129→0.4874（+0.175）、MacAUC 0.7363→0.7512，**证实 3d→d
压缩是 attn2 崩盘的主因**；但 MacF1 仍低于 v1（0.487 vs 0.524），且 MacAUC
已几乎打平（0.751 vs 0.755）→ 剩余差距属校准/阈值而非排序。attn4（v1 特征
+ 上下文）0.4852 < v1 0.5239 → **注意力上下文 c 本身是净噪声**（超小采样邻域
上的可学习注意力无正贡献，与文献结论一致）。结论：修复瓶颈值得做（attn3 曾
进入代码库，已在 `8a1bc79` 回退），但注意力路线整体仍不优于 v1。

**ms5 放大差异的机制**：短轨迹 → 2 节点图占比升高 → c=0 更常见，attn2 只剩
压缩 pair 路径且注意力参数在少数图上拿到高方差梯度；v1 无此通路，短轨迹反而
起到正则化与奖励平滑作用（MacF1 0.5090→0.5239）。

**对策（待实验）**：q/k 加 LayerNorm + 可学习温度（防熵坍缩）、
best-threshold F1 分离校准问题；k_hops=2 已实验（正面，但未超 ms5/h128
最优，见 TL;DR 第 5 条）；attn3/attn4 的 `--readout` 切换已随回退
（`8a1bc79`）移除，重试需先恢复代码。
