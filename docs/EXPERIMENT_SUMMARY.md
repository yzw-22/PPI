# SHS27k 实验总结（超参数调优 / sampler 打分架构 / bfs-dfs 划分对比）

> 记录 main 分支超参数（gamma、hidden、epochs、seed、max_steps、k_hops）的
> 全部对比实验。均为 CPU 本地运行，与 CUDA 服务器结果同分布但数值不可
> 直接混用；正式结论以多 seed 均值±std 为准。

## 结论（TL;DR）

1. **当前最优配置**：`v1 readout + hidden 128 + gamma 0.9 + 20 epochs +
   max_steps 5`（seed 42）：test MacAUC 0.7553 / MicAUC 0.7734 /
   **MacF1 0.5239** / MicF1 0.5758，训练 1406 s（~47% 快于 ms10）。
   （当前代码已为 res-score 打分，同配置 3-seed 配对见第 7 条。）
2. **gamma 0.9 > 1.0**：对 v1 正面（MacF1 0.5025 vs 0.4765，s42；注意 g1.0
   对照来自 10ep 记录，epoch 数与 gamma 混杂，20ep/g1.0 未跑，见待办），
   docs 示例命令即 0.9。
3. **hidden 128 > 256**：小数据（train 4562）下降容量减少过拟合且提速 ~35%
   （v1 +0.007，s42/20ep/g0.9）。
4. **k_hops 2 > 1**（s42/ms10/h256/g0.9，40ep vs 20ep）：val MacAUC 0.7587 vs
   0.7390，前 20 epoch 逐 epoch 对比 17/20 领先；test 四项全升（MacAUC
   0.7483 vs 0.7253、MicAUC 0.7609 vs 0.7493、MacF1 0.5246 vs 0.5025、MicF1
   0.5458 vs 0.5295）；mean_reward 0.01→0.019（候选池扩大后采样器学到更多）。
   但 test 仍低于 ms5/h128 最优（MacAUC 0.7483 vs 0.7553、MicF1 0.5458 vs
   0.5758，MacF1 持平 0.5246 vs 0.5239），且 40ep 后半段无额外收益（best
   epoch 34，35–40 回落）→ 单 seed，待扩 seed 验证。
5. **value baseline 删除（3 seed 配对，s42/s111/s123，20ep/g0.9/h256/ms10/k1）**：
   AUC/F1 差异全部在配对 ±1σ 内（valAUC +0.002±0.008、test MacAUC −0.003±0.008、
   MacF1 −0.017±0.055、MicF1 −0.019±0.073，F1 方向随 seed 翻转：s42/s111 降、
   s123 升）——**无显著指标收益**；唯一稳定收益是省时 ~13%（−648±132 s）与
   少一套参数。s111 无 baseline 版 bestEp=3 早峰后漂移，稳定性略降。结论：
   删除可接受（指标无显著损失）但非净提升。
6. **方差纪律**：指标波动大（MacF1 0.36~0.52），任何结论需同 seed 配对 +
   多 seed 验证。
7. **sampler 打分架构 v1-res（3 seed 配对，s42/s111/s123，ms5/h128/g0.9/20ep）**：
   `concat(state, cand) → Linear(2d→d)` 加回投影 state（残差）→
   `Linear(d→d//2) → LayerNorm → Tanh → Linear(d//2→1)` 打分头，取代原
   LeakyReLU pairwise MLP。配对 diff 全部为正：valAUC +0.008±0.008、MacAUC
   +0.004±0.005、MicAUC +0.005±0.005、**MacF1 +0.050±0.052（3/3 正）**、
   MicF1 +0.032±0.041（2/3 正，s42 微负 −0.013）；方差显著更小（MacF1 std
   0.024 vs 0.075，最差 seed s111 0.358→0.481）。结论：res-score 不劣于 v1
   且稳定性明显更好，保留为默认架构；与 h256/ms10、k2 组合未测。
8. **res-score × k_hops 2（3 seed 配对，s42/s111/s123，ms5/h128/g0.9/20ep，
    纯净配置）**：k2 vs k1 配对 diff 全部落在方差内——valAUC −0.001±0.010、
    MacAUC −0.001±0.013、MicAUC +0.000±0.020、**MacF1 +0.010±0.021（2/3 正，
    s42 −0.020/s111 +0.027/s123 +0.022）**、MicF1 +0.014±0.029（2/3 正）；
    k2 3-seed MacF1 0.5245±0.019 vs k1 0.5148±0.024。**无显著差异，默认保持
    k1**；s123 单点 MacF1 0.5516 / MicF1 0.5879 为全部实验新高（单点不判定）。
    与 TL;DR 第 4 条（v1/ms10/h256/40ep 混杂下 k2 正面）不矛盾：该正面来自
    epoch 数混杂，纯净配对下 k2 收益消失。
9. **SHS27k dfs 划分（3 seed，s42/s111/s123，ms5/h128/g0.9/20ep，首次
    dfs 实验）**：MacF1 0.6006±0.0071（0.6008/0.6075/0.5933）、MacAUC
    0.8186±0.0040、MicAUC 0.8461±0.0077、MicF1 0.6557±0.0120、valMacAUC
    0.8224±0.0051（bestEp 14/15/20，无早峰）。与 bfs 同配置 res-score 基线
    （MacF1 0.5148±0.0238、MacAUC 0.7509±0.0075）对比：**五项指标 3/3 大幅
    正差**（MacF1 +0.086±0.035、MicF1 +0.114±0.050、MacAUC +0.068±0.010、
    MicAUC +0.072±0.024、valMacAUC +0.066±0.017），且方差仅为 bfs 的约 1/4。
    **注意：两划分 train/val/test 成员不同（train 4571 vs 4562；dfs 测试集
    ES 1215/NS 314 = 79.5% 训练可见，bfs 为 1078/460 = 70.1%），差值是划分
    难度属性而非模型改进**——dfs 划分任务系统性更容易、训练更稳定；所有
    历史结论基于 bfs，跨划分数值不可混用。
10. **SHS148k dfs 划分（3 seed，s42/s111/s123，ms5/h128/g0.9/20ep，首次
    SHS148k 实验）**：MacF1 0.6355±0.0139（0.6278/0.6515/0.6271）、MacAUC
    0.8501±0.0109、MicAUC 0.8812±0.0094、MicF1 0.7091±0.0152、valMacAUC
    0.8519±0.0066；bestEp 全部 19（最后 epoch 仍在改善，20ep 可能不足）。
    与 SHS27k dfs 同配置（TL;DR 第 9 条）对比：**五项指标 3/3 正差**
    （MacF1 +0.035±0.009、MicF1 +0.053±0.013、MacAUC +0.032±0.009、
    MicAUC +0.035±0.007、valMacAUC +0.029±0.005）。**注意：跨数据集不可
    配对**——差异来自更多训练数据（train 26599 vs 4571 PPI，5.8×）与更高
    测试可见性（86.1% vs 79.5%），属数据规模/难度属性而非模型改进；单次
    训练 ~4.1 h（SHS27k dfs 的 10×），CPU 预算需注意。
11. **SHS27k 新随机 bfs 划分（3 seed，s42/s111/s123，ms5/h128/g0.9/20ep，
    数据源 `dataset_ppisplit/`，与旧 bfs 为不同划分：train 索引交集仅 69%）**：
    MacF1 0.5479±0.0158（0.5538/0.5300/0.5599）、MacAUC 0.7968±0.0200、
    MicAUC 0.8129±0.0129、MicF1 0.5820±0.0185、valMacAUC 0.8136±0.0100
    （bestEp 14/16/18，无早峰）。与旧 bfs res-score 基线（TL;DR 第 7 条）
    对比：**五项指标 3/3 正差**（MacF1 +0.033±0.014、MicF1 +0.040±0.022、
    MacAUC +0.046±0.013、MicAUC +0.039±0.008、valMacAUC +0.057±0.005）。
    **结论：划分生成过程的随机波动本身即达 MacF1 ~0.03-0.06 量级**（旧 bfs
    偏难）；跨划分不可配对，但 3/3 符号一致。难度层次：旧 bfs 0.515 <
    新 bfs 0.548 < dfs 0.601（同配置）。
12. **SHS148k bfs 划分（3 seed，s42/s111/s123，ms5/h128/g0.9/20ep，数据源
    `dataset_ppisplit/`，SHS148k 首次 bfs）**：MacF1 0.4163±0.0153
    （0.4339/0.4077/0.4072）、MacAUC 0.7661±0.0047、MicAUC 0.8178±0.0065、
    MicF1 0.5743±0.0611、valMacAUC 0.7733±0.0017；**s42/s123 崩溃
    （bestEp=1 早峰，验证 AUC 全程单调下降），仅 s111 正常（bestEp 11）**。
    与 SHS148k dfs（TL;DR 第 10 条）对比：**五项 0/3 正，灾难性负差**
    （MacF1 −0.219±0.025、MicF1 −0.135±0.063、MacAUC −0.084±0.016、
    MicAUC −0.063±0.013、valMacAUC −0.079±0.008）。标签分布与 dfs 几乎
    相同（overall pos 0.325 vs 0.328，逐类差 <0.02）排除标签偏置；train 图
    节点更少（3836 vs 4494）。**结论：SHS148k 上 bfs 划分训练不稳定且全面
    远低于 dfs**——bfs 划分效应在更大数据上被放大（SHS27k 上 bfs<dfs 差距
    ~0.05-0.09，SHS148k 上达 0.22）；根因经 G0-only 诊断（TL;DR 第 13 条）
    确定为划分数据属性（train 稠密核心 vs val 稀疏外围），与 RL 机制无关。
13. **SHS148k G0-only 诊断（max_steps=0，去掉子图扩展与 REINFORCE；bfs 3
    seed s42/s111/s123 + dfs 对照 s42，20ep/h128/g0.9，其余同配置）**：
    bfs valMacAUC 0.7327±0.0025（bestEp 7/19/10 噪声峰，val 曲线 0.70-0.73
    振荡**仍无上升趋势**）、testMacF1 0.4282±0.0153；dfs 对照 G0-only 即达
    valMacAUC 0.8468 / testMacF1 0.6394（≈ ms5 全配 0.8476/0.6278）。
    **结论：① SHS148k bfs 的"val 不随训练改善"在无子图、无 RL 时依然存在，
    崩溃根因是 bfs 划分的数据属性**（train 为网络稠密核心——3836 节点承载
    26678 边、1-hop 区域内边中位 837 vs val 172、38% 节点度>50、最高复用
    节点出现在 43.8% 目标区域；val 为稀疏外围且 50.5% 的 PPI 两端节点均未
    在 train 出现——标签-特征映射不可迁移），与 sampler/RL 机制无关；
    **② dfs 上子图通路贡献≈0**（ms0 ≈ ms5），SHS148k dfs 高指标基本来自
    pair 特征本身（G0 最小拓扑），sampler 在 dfs 上近乎冗余；**③ bfs 上子图
    通路仍有 +0.041±0.003 valMacAUC 即时增益**（ms5 0.7733 vs ms0 0.7327，
    3/3 正）但无法随训练增长。
14. **SHS148k dfs 长训练与 ms0 等价性（3 seed s42/s111/s123，20ep；
    +s42 40ep 探测）**：ms0（无子图/无 RL）3-seed valMacAUC 0.8482±0.0013 /
    testMacF1 0.6259±0.0117 vs ms5 全配 0.8519±0.0066 / 0.6355±0.0139
    ——**逐 seed 配对差全部 ≤0.011 且符号混杂，无显著差异，dfs 上 sampler/RL
    近乎冗余确认（3-seed），省时 ~14×**；s42 40ep：bestEp 18→23、bestVal
    0.8468→0.8554（+0.009，20ep 未饱和），但 testMacF1 0.6394→0.6324
    （−0.007，单点噪声内）——**长训练 val 继续改善但 test F1 未确认提升**；
    ms5-30ep 验证结果待补。
15. **SHS148k dfs 长训练 3-seed 与 hidden 探测（ms0 形态，40ep 3-seed
    s42/s111/s123 + h256 3-seed + 60ep 配对）**：40ep vs 20ep（ms0 h128
    配对）valMacAUC +0.0075±0.0014（**3/3 一致**，0.8482→0.8557±0.0004），
    testMacF1 +0.0093±0.0179（2/3 正不显著，0.6259→0.6352±0.0106）；
    **40ep-ms0-h128 相对 20ep-ms5 全配基线：valMacAUC +0.004（0.8557 vs
    0.8519）、testMacF1 持平（0.6352 vs 0.6355）、方差更小（0.0004 vs
    0.0066）、成本 ~14× 低**；h256 vs h128（40ep，3-seed 配对）
    testMacF1 −0.0006±0.0181（2/3 正）——**s42 单点 +0.014 被 s111 −0.021
    抵消，无显著差异**，SHS27k 的"h128 更优"结论在大数据域不成立但 h256
    也非更优；60ep（s42 配对）h256 bestEp 不变（34）、h128 bestEp 23→57
    但 testMacF1 仅 +0.0068（噪声内）——**40ep 为成本-收益甜点**。
16. **SHS148k random 划分（3 seed，s42/s111/s123，ms0/h128/g0.9/20ep，
    首次 random）**：valMacAUC 0.9660±0.0001、testMacF1 0.8444±0.0109
    （0.8515/0.8318/0.8499）、MacAUC 0.9685±0.0004、MicF1 0.8808±0.0015；
    bestEp 全 20（20ep 未饱和）。**注意：指标虚高为划分属性而非模型改进**
    ——test 可见性 BS 8598（96.5%）/ ES 294 / NS 6（dfs 为 BS 0 / ES 7655 /
    NS 1242）：random 按 PPI 随机抽样，train/test 节点高度共享，96.5% 测试
    对两端节点在训练图中见过，预测退化为"已见节点模式匹配"；跨划分不可
    混比（TL;DR 第 6 条纪律），random 的 0.8444 与 dfs 的 0.6355 不可直接
    对比，报告时须标注划分。
17. **SHS27k dfs ms0 3-seed（s42/s111/s123，h128/g0.9，20ep 纯净配对，
    无混杂）**：testMacF1 0.6295±0.0172（0.6129/0.6284/0.6473）vs ms5
    基线 0.6006±0.0071——**配对 diff +0.029±0.022，3/3 正**；valMacAUC
    0.8413±0.0039 vs 0.8186±0.0049（+0.019，3/3 正）；40ep 无增量
    （bestEp 17/17/18 均 ≤20 饱和，40ep 与 20ep 逐字节一致）。**结论：
    去掉子图采样（ms0）在 SHS27k dfs 上显著提升指标——小数据域下 RL
    采样的非平稳噪声/子图过拟合净有害**；结合 SHS148k dfs ms0 持平
    （TL;DR 第 14 条），**sampler/RL 组件在两个 dfs 数据集上均无正向贡献，
    G0-only predictor 为确认的最优形态**（SHS27k dfs MacF1 0.6006→0.6295；
    SHS148k dfs 0.6355→0.6352 持平但成本 ↓14×）。

## 关键实验结论

- **gamma 0.9**：v1 的 F1 明显受益（s42：MacF1 0.5025 vs g1.0 的 0.4765；
  但 g1.0 对照来自 10ep 记录（总表 `v1 42 10 1.0` 行），epoch 数与 gamma
  混杂）。
- **hidden 128**：F1 提升（v1 +0.007，s42/20ep/g0.9），
  epoch 时间 130 s vs 200 s（−35%），支持小数据域过拟合假设。
- **max_steps 5 vs 10**（s42/20ep/g0.9/h128）：v1 全面受益——MacAUC
  0.7275→0.7553、MacF1 0.5090→0.5239，epoch 时间 130 s→70 s（−47%，
  20ep 全程 1406 s）。
- **k_hops 2 vs 1**（s42/ms10/h256/g0.9，40ep vs 20ep）：val MacAUC 0.7587
  vs 0.7390，前 20 epoch 逐 epoch 17/20 领先（多数 +0.02~+0.07）；test 四
  项全升（见 TL;DR 第 4 条）。mean_reward 0.010→0.019：候选池扩大缓解了
  k1 下 frontier 快速耗尽导致的"被迫扩张"，采样器学到更充分的子图。但
  best epoch 34，40ep 后半段回落，且 test 仍低于 ms5/h128 最优
  （MacAUC 0.7483 vs 0.7553、MicF1 0.5458 vs 0.5758）——k2 方向正面，
  单 seed，待扩；k2 与 ms5/h128 的组合未测。
- **value baseline 删除**（s42 单点 → 3 seed 配对扩展，20ep/g0.9/h256/ms10/k1）：
  s42 上曾见 val MacAUC 0.7509 vs 0.7390 且 F1 降 ~0.025 的"排序-校准分离"；
  扩到 s111/s123 配对后该签名不成立——逐 seed 方向翻转（s42 MacF1 −0.024、
  s111 −0.081、s123 +0.053），3 seed 配对 diff 全部在 ±1σ 内（见 TL;DR
  第 5 条）。**value baseline 对最终指标无显著影响**；稳定收益仅省时 ~13%
  （均值 4258 s vs 4906 s，配对 std 132 s）与少一套参数。s111 no-val 的
  bestEp=3 早峰提示无 baseline 时策略梯度方差更大、验证曲线更抖。
- **sampler 打分 v1-res**（3 seed 配对，s42/s111/s123，ms5/h128/g0.9/20ep）：
  残差式 pair 投影 + LN/Tanh 打分头。配对 diff：MacAUC +0.004±0.005、
  MicAUC +0.005±0.005、MacF1 +0.050±0.052（3/3 正）、MicF1 +0.032±0.041
  （s42 −0.013、s111 +0.087、s123 +0.023）。关键收益在稳定性：v1 的 s111
  崩溃点（MacF1 0.358，bestEp=2 早峰）被 res 修复为 0.481（bestEp=14）；
  res 3-seed MacF1 std 0.024 vs v1 0.075。AUC 增益较小但 3/3 正。epoch 时间
  相当（约 60-80 s）。
- **res-score × k_hops 2**（3 seed 配对，ms5/h128/g0.9/20ep，纯净配置）：
  配对 diff 全部在 ±1σ 内（见 TL;DR 第 8 条）：s111/s123 正面（MacF1
  +0.027/+0.022）但 s42 负向（−0.020），均值 MacF1 +0.010±0.021、MicF1
  +0.014±0.029，AUC 三项 ≈0。s123 单点 MacF1 0.5516 / MicF1 0.5879 为全部
  实验新高（不判定）。**k2 无系统性收益，默认 k_hops=1 保持不变**；v1 时代
  k2 正面结论（TL;DR 第 4 条）由 40ep vs 20ep 混杂产生，本实验以纯净配对修正。
- **SHS27k dfs 划分**（3 seed，s42/s111/s123，ms5/h128/g0.9/20ep，res-score
  默认代码，无任何改动）：MacF1 0.6006±0.0071 / MacAUC 0.8186±0.0040 /
  MicAUC 0.8461±0.0077 / MicF1 0.6557±0.0120 / valMacAUC 0.8224±0.0051；
  bestEp 14/15/20 均无早峰。与 bfs 同配置（TL;DR 第 7 条）均值差五项全正：
  MacF1 +0.086±0.035、MicF1 +0.114±0.050、MacAUC +0.068±0.010、MicAUC
  +0.072±0.024、valMacAUC +0.066±0.017；dfs 方差显著更小（MacF1 std 0.007
  vs 0.024）。**归因：划分难度属性，非模型改进**——dfs 测试集训练可见占比
  79.5%（bfs 70.1%），train/val/test 成员不同，val 与 test 同时更易；该差异
  远超全部历史结构/超参效应的量级（最大正效应 res-score 也仅 MacF1
  +0.050±0.052），提示划分方式是当前最大"杠杆"，跨划分结论不可混用。
- **SHS148k dfs 划分**（3 seed，s42/s111/s123，ms5/h128/g0.9/20ep，
  res-score 默认代码，首次 SHS148k）：MacF1 0.6355±0.0139 / MacAUC
  0.8501±0.0109 / MicAUC 0.8812±0.0094 / MicF1 0.7091±0.0152 / valMacAUC
  0.8519±0.0066；bestEp 全部 19（**最后 epoch 仍在改善，20ep 上限可能未到**，
  与 SHS27k 系列 bestEp 14/15/20 不同）。与 SHS27k dfs（TL;DR 第 9 条）均值
  差五项全正：MacF1 +0.035±0.009、MicF1 +0.053±0.013、MacAUC +0.032±0.009、
  MicAUC +0.035±0.007、valMacAUC +0.029±0.005。**归因：数据规模与难度属性**
  ——train 26599 vs 4571 PPI（5.8×）、测试可见 86.1% vs 79.5%；跨数据集不可
  配对，非模型改进。训练预算：单次 ~4.1 h（SHS27k dfs 的 10×），3 并行 CPU
  （OMP=2）epoch ~700-790 s。冒烟（1-epoch）通过后跑全量，全链路无报错。
- **SHS27k 新随机 bfs 划分**（3 seed，s42/s111/s123，ms5/h128/g0.9/20ep，
  数据源 `dataset_ppisplit/`，与旧 bfs 不同划分）：MacF1 0.5479±0.0158 /
  MacAUC 0.7968±0.0200 / MicAUC 0.8129±0.0129 / MicF1 0.5820±0.0185 /
  valMacAUC 0.8136±0.0100（bestEp 14/16/18 无早峰）。vs 旧 bfs（TL;DR 第
  8 条）五项 3/3 正差（MacF1 +0.033±0.014、MacAUC +0.046±0.013、valMacAUC
  +0.057±0.005）。**划分随机波动量级 MacF1 ~0.03-0.06，大于除 res-score 外
  的全部已测结构/超参效应**；提示"换划分"本身即可产生显著指标差异，跨划分
  结论（含本系列全部 bfs 历史结论）须限定划分实例。
- **SHS148k bfs 划分**（3 seed，s42/s111/s123，ms5/h128/g0.9/20ep，数据源
  `dataset_ppisplit/`）：MacF1 0.4163±0.0153 / MacAUC 0.7661±0.0047 /
  MicAUC 0.8178±0.0065 / MicF1 0.5743±0.0611 / valMacAUC 0.7733±0.0017；
  **s42/s123 崩溃（bestEp=1，验证 AUC 自 epoch 1 后单调下降）**，仅 s111
  正常（bestEp 11）。vs SHS148k dfs（TL;DR 第 10 条）**五项 0/3 正、
  MacF1 −0.219±0.025**。标签分布与 dfs 几乎相同（overall pos 0.3252 vs
  0.3281、逐类差 <0.02）排除标签偏置；train 图节点更少（3836 vs 4494，
  边数相近 26678 vs 26599）。机制：bfs 划分在 SHS148k 上训练不稳定（早峰
  签名与既往崩溃案例同类），bfs<dfs 效应在更大数据上放大（SHS27k 差距
  0.05-0.09 → SHS148k 0.22）；根因经 G0-only 诊断（下述条目）确定为划分
  数据属性，与 RL 机制无关。
- **SHS148k G0-only 诊断**（max_steps=0，去掉子图扩展与 REINFORCE；bfs 3
  seed s42/s111/s123 + dfs 对照 s42，20ep/h128/g0.9，其余同配置）：bfs
  valMacAUC 0.7327±0.0025 / testMacF1 0.4282±0.0153，val 曲线 0.70-0.73
  振荡无上升趋势（bestEp 7/19/10 为噪声峰）——**崩溃的 val 停滞与 RL/子图
  机制无关，是 bfs 划分数据属性**：train 为网络稠密核心（3836 节点承载
  26678 边、1-hop 区域内边中位 837 vs val 172、38% 节点度>50、最高复用
  节点出现在 43.8% 目标区域），val 为稀疏外围且 50.5% PPI 两端节点均未在
  train 出现，标签-特征映射不可迁移；dfs 对照 G0-only 即达 0.8468/0.6394
  （≈ms5 全配 0.8476/0.6278）→ **dfs 上子图通路贡献≈0，高指标来自 pair
  特征本身**；bfs 上子图通路仍有 +0.041±0.003 valMacAUC 即时增益（3/3
  正）但无法随训练增长。
- **实现细节**：readout 切换曾由 `--readout {v1,attn,attn2}` 控制，attn
  机制代码已在 `8a1bc79` 回退；当前模型只有 v1 路径（predictor 与 23c984c
  逐字节一致；sampler 另在 `8b22f09` 删除了 value_head），历史 attn
  checkpoint 不再兼容当前代码。
