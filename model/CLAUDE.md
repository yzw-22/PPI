# 任务目标
你需要实现一个基于强化学习的蛋白质-蛋白质相互作用（PPI）预测系统。系统包含两个核心模块：**子图采样器** 和 **预测器**。两个模块需通过交替训练策略进行优化。

请按照以下架构规范与算法逻辑编写代码。

---

## 1. 子图采样器

### 1.1 图定义与初始化
- **图结构**：节点代表蛋白质，边由 PPI 网络提供。
- **输入**：PPI 节点对 `(u, v)`。
- **初始状态**：初始子图 `G_0 = {u, v}`。

### 1.2 采样过程
对于时间步 `t >= 0` 的子图 `G_t`，定义其相邻节点集合为 `N_t`。
- **动作空间**：从节点集合 `N_t - G_t` 中选择一个节点加入子图。
- **终止条件**：达到最大扩展次数 `T_max` 或 `N_t - G_t` 为空。
- **状态表征 (`s_t`)**：计算当前子图 `G_t` 中所有节点 ESM embedding 的均值，作为状态向量。

### 1.3 动作策略
对于候选相邻节点 `i`，构建其表征向量 `neighbor_i`。使用 **Scaled Dot-Product Attention** 计算节点选择概率：
1. 计算相似度得分：`score_i = dot(Query(state), Key(neighbor_i)) / sqrt(d)`
2. 通过 Softmax 将得分转化为概率分布 `probs`。
3. **基准网络**：实现一个价值网络 `V(s_t)`，输出标量价值，用于 REINFORCE 算法的方差缩减。

### 1.4 训练与推理模式
- **训练模式**：从 `Categorical(probs)` 中采样节点，记录 `log_prob`，使用 REINFORCE 策略梯度更新参数。
- **推理模式**：使用 `argmax` 选择概率最大的节点。

## 2. 孤立 PPI 对处理机制

### 2.1 定义参考
孤立（松散孤立）PPI 对的具体定义参见 `dataset/CLAUDE.md`。

### 2.2 虚拟代理注入
对于孤立 PPI 对 `(u, v)`，假设当前数据集（训练集或测试集）的节点集合为 `node_set`：
- 计算 `node_set` 中各节点与 `u`/`v` 的余弦相似度。
- 选取相似度最大的蛋白质节点作为**虚拟代理**加入子图。

### 2.3 Agent 决策指令
> **Agent 注意**：评估“显式利用余弦相似度的数值”作为额外特征输入是否能提升模型性能。若你认为该方案有效，请设计具体的特征融合方案（如拼接到状态向量或邻接节点表征中），并在编码前输出方案设计以征求同意。

## 3. 预测器

### 3.1 模型架构
- **输入**：时间步 `t >= 1` 的子图 `G_t`。
- **图神经网络 (GNN)**：基础结构为 `GAT + 残差连接 + LayerNorm`。
  > **Agent 决策指令**：参考 `ref/` 目录下的 `GraphTransformer` 文件。评估其相较于基础 GAT 的优势。若有显著提升，可选择使用 GraphTransformer 替代或结合使用。
- **Readout 机制**：采用 Pairwise Readout，对目标节点对 `(u, v)` 的特征 `h_u` 和 `h_v` 进行拼接：`[h_u; h_v; h_u ⊙ h_v; |h_u - h_v|]`
- **输出层**：通过 MLP 输出 **7 维 Sigmoid 概率**（多标签分类）。

### 3.2 损失计算与奖励构造
- **损失函数**：将模型输出的 7 维概率与 multi-hot 标签计算 Binary Cross-Entropy (BCE) 损失。
- **Baseline 损失**：将初始图 `G_0 = {u, v}` 输入预测器，计算得到损失 `l_0`。
- **子图损失**：当前子图 `G_t` 输入预测器，计算得到损失 `l_t`。
- **强化学习奖励**：`r_t = l_0 - l_t`（表征引入子图信息后的性能提升），用于 Sampler 的 REINFORCE 训练。

---

## 4. 训练策略

采用交替训练策略固定一方、更新另一方：

### 4.1 Sampler 训练步
- **固定模块**：Predictor。
- **更新模块**：Sampler。
- **优化目标**：REINFORCE 策略梯度更新。
- **奖励信号**：`reward = r_t = l_0 - l_t`（结合 Baseline 价值网络 `V(s_t)` 进行方差缩减）。

### 4.2 Predictor 训练步
- **固定模块**：Sampler（强制设置为 `argmax` 推理模式）。
- **更新模块**：Predictor。
- **优化目标**：BCE 监督损失 `l_t`。

## 5. 评估指标

模型性能评估需输出以下两个指标：
- **AUC** (Area Under the ROC Curve)
